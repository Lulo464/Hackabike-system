# EcoHub prototype – downloads

Files produced for the **EcoHub** dashboard prototype (a separate design study,
not part of the running station).

| File | What it is |
|---|---|
| `ecohub-bikestation-nodered.json` | alternative Node-RED flow in the EcoHub look, see [README-bikestation-nodered.md](README-bikestation-nodered.md) |
| `dashboard-desktop.png`, `dashboard-mobile.png`, `dashboard-full.png` | screenshots of the prototype |

The station itself runs the flow in [`nodered/flows.json`](../../nodered/flows.json).
